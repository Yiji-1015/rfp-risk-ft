# 경계 100건 zero-shot 재라벨링 — 라벨 재현성 확인

- 실행일: 2026-09-03
- 목적: 견적↔계약 경계 오답이 모델 한계인지 라벨 노이즈인지 가르기 위해, 라벨러가 자기 라벨을
  얼마나 재현하는지 잰다. 451건 재라벨링에 앞선 파일럿.
- 표본: `data/samples/boundary_recheck_100_v0.1.0.jsonl` — 924건 중 동결 앵커를 제외한
  `견적반영`·`계약·질의검토` 451건에서 문서·라벨 비례 층화 추출 100건 (계약 52 / 견적 48, seed 42)
- 조건: Claude Sonnet 5, effort medium, 프롬프트 v5, **zero-shot** 2회. 동결 라벨은 층화 few-shot이므로
  두 회차끼리의 일치는 같은 조건 반복이고, 동결과의 일치는 전략 차이를 포함한다.
- 결과: `reports/current/claude_runs/boundary_recheck_100_zeroshot_rep{1,2}/`
- 토큰: 2회 합계 입력 139,744 / 캐시 읽기 688,000 / 출력 82,934

동결 + 재실행 2회의 3표 기준: 만장일치 아님 18/100, **다수결이 동결과 다름 12/100**.

## 읽기

1. **라벨 노이즈는 실재하지만 경계 오답의 주범은 아니다.** 경계 라벨의 약 12~15%가 zero-shot
   재실행과 어긋나고, 그중 절반 이상이 층화 few-shot과 zero-shot의 **전략 차이**다(같은 조건
   반복 불일치 6% 대 동결과의 불일치 15%). 451건으로 외삽하면 약 54건이 뒤집힌다.
2. **라벨이 안정적인 82건에서도 모델은 0.59~0.63밖에 못 맞힌다.** 라벨을 완벽히 고쳐도 경계
   정확도는 이 근처에 머문다. 뒤집힌 12건도 모델이 재실행 라벨을 맞힌 건 2~5건뿐이라,
   재라벨링으로 회수되는 오답은 거의 없다.
3. 따라서 **451건 재라벨링은 점수 목적으로는 하지 않는다.** 이 100건 결과는 라벨 재현성
   상한(같은 조건 94%, 전략 교차 85%)을 보고할 근거로 쓴다. 2026-09-03 워크로그의
   "문서 밖 지식" 결론이 라벨 쪽에서도 독립적으로 지지된다.
