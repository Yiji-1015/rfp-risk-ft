# sLLM LoRA 결과와 앙상블 비교

작성: 2026-09-09. GPU 결과 커밋: `20b841c`.

**v5 주 구성은 유지한다.** sLLM 포함 최고 조합의 개선은 +0.0113으로, 사전 채택 기준 +0.016에 못 미쳤다. 경계 혼동은 117→111건으로 소폭 감소했다.

## 실제 실행 조건

- Qwen2.5-7B-Instruct, CUDA, seed 42, 3 epochs, LoRA r=16.
- lr 1e-4, batch 4, grad accumulation 4, eval batch 4, 본문 512토큰.
- `no_quant=true`: 4bit QLoRA가 아닌 양자화 없는 LoRA 실행이다.
- v5·v7 모두 동일한 system_prompt. v7 라벨링 프롬프트 전체를 제공한 실험은 아니다.
- 각 라벨셋에서 학습 11/검증 1/평가 1 문서의 13-fold LODO, 평가 1,345건.
- 두 버전의 정답이 다르므로 버전 사이 절대 점수를 동일 시험 결과처럼 비교하지 않는다.

## 판단

- **v5:** Qwen 단독 0.6438은 large 0.6555보다 낮다. wc+large+Qwen은 0.6827로 지정 기준 0.6714보다 +0.0113이나, 기존 seed 9쌍 범위 0.666~0.683 안이다. 주 구성 교체 근거로 삼지 않는다.
- **v5 경계:** 지정 조합 대비 전체 오답은 10건, 경계 혼동은 6건 줄었다. 보완 효과는 있지만 경계를 해결했다고 표현하지 않는다.
- **v7:** Qwen 단독은 large보다 +0.0254다. 그러나 두 모델의 오답은 338건으로 같고, 경계 혼동은 96→110으로 늘었다. 기존 앙상블 대비 +0.0129는 하한 아래다.
- **지표 차이:** v7의 fold 평균 최고는 Qwen 단독, 통합 OOF 최고는 wc+large+Qwen이다. 문서별 동일 가중 평가와 전체 표본을 합친 평가를 구분한다.
- **범위:** sLLM seed는 하나다. 0.016은 기존 변동으로 얻은 선별 기준이며 이번 실험의 유의성 검정 결과가 아니다.
- **해석:** 디코더, system 지시, 라벨 토큰 학습, 로그확률 판정을 함께 바꿨다. 문서 밖 상식의 효과만 분리한 실험은 아니다.
- **중첩 선택:** 저장된 OOF를 대상으로 남은 문서의 통합 F1에 따라 조합을 고르는 진단이다. 모델 재학습을 포함한 완전한 nested CV와 구분한다.
