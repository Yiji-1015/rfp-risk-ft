# 006. 문서 간 요구사항 중복

**상태**: 미해결 (문서 단위 분할로 막히지 않는 누수)

## 무엇이 문제인가

공공 RFP는 표준 문구를 공유한다. **기관이 달라도 같은 조항이 그대로 나온다.**

분할은 문서 단위로 한다(§10.1). 같은 문서 안의 반복은 이걸로 막힌다. 그런데
**문서를 넘는 반복은 정의상 학습 fold와 평가 fold에 갈라져 들어간다.** 막을 방법이
분할에 없다. 이게 006이다.

## 관측

문자 3~4gram TF-IDF 코사인 유사도로 **다른 문서**의 최근접 요구사항을 재면:

| 유사도 | 건수 | 비율 |
|---|---:|---:|
| ≥ 0.9 | 22 | 2.1% |
| ≥ 0.8 | 50 | 4.9% |
| ≥ 0.7 | 100 | 9.8% |
| ≥ 0.6 | 123 | **12.0%** |
| ≥ 0.5 | 167 | 16.3% |

중앙값은 0.209로 대부분은 안 겹친다. 문제는 겹치는 **12%**다.

### 겹치는 것들은 라벨도 같다

유사도 ≥0.6인 문서 간 쌍 85개에서 **주 라벨 일치율 95.3%**다.

라벨러가 반복 조항에 일관되게 판정했다는 뜻이라 라벨 품질로는 좋은 신호다.
동시에 **모델이 외우면 맞출 수 있다**는 뜻이기도 하다.

### 표준 문구 유형에 몰려 있다

| 정본 유형 | 근접중복 | 비율 |
|---|---:|---:|
| 품질 | 21/64 | 32.8% |
| 프로젝트관리 | 49/151 | 32.5% |
| 제약사항 | 18/62 | 29.0% |
| 데이터 | 19/77 | 24.7% |
| 테스트 | 4/41 | 9.8% |
| 보안 | 2/88 | 2.3% |

감리 대응, 개인정보보호법 준수, 요구사항 관리, 기술적용계획표 같은 조항이다.

### 문서마다 노출 정도가 전혀 다르다 — 이게 제일 나쁘다

| 문서 | 근접중복 | 비율 |
|---|---:|---:|
| mfds_drug_ai_review | 44/192 | 22.9% |
| korail_genai_isp_ismp | 11/49 | 22.4% |
| kexim_ai_platform | 26/137 | 19.0% |
| koen_ai_infrastructure | 18/101 | 17.8% |
| kangwon_land_genai | 6/50 | 12.0% |
| kac_ai_work_platform | 6/86 | 7.0% |
| incheon_airport_digital_work | 4/78 | 5.1% |
| defense_intelligent_platform | 7/169 | 4.1% |
| genai_incident_response | 1/67 | 1.5% |
| **ccrs_ai_platform** | **0/95** | **0.0%** |

`mfds`를 평가 fold로 쓰면 **평가 표본의 22.9%가 학습에 사실상 존재한다.**
`ccrs`를 쓰면 **0%**다. 같은 모델이 어느 문서를 평가하느냐에 따라 공짜 점수를
23%p까지 다르게 받는다.

003(문서별 라벨 분포 편차)과 겹쳐서 **fold 비교 가능성을 두 번 망가뜨린다.**

## 예시

```
sim 1.000  mfds:PMR-001  ==  kexim:PMR-006   (둘 다 통상수용)
  "추진조직 외에 본 사업을 성공적으로 수행할 수 있도록 지원 또는 자문조직의
   구성을 제시할 수 있으나, 수행 역할과 결과물이 명확해야 함"

sim 0.985  korail:DAR-009  ~  mfds:DAR-025   (둘 다 통상수용)
  같은 조항인데 글머리 기호만 다르다 (⚪/◦, ­/-)
```

## 대응

아직 정하지 않았다. 후보는 셋이고 전부 대가가 있다.

1. **근접중복을 평가에서 제외하고 별도 보고** — 평가 표본이 문서에 따라 최대 23%
   줄어든다. 대신 "외운 것"과 "판단한 것"이 분리된다.
2. **그대로 두고 노출률을 함께 보고** — 점수 옆에 그 fold의 근접중복 비율을 적는다.
   가장 싸지만 해석은 읽는 사람 몫으로 남는다.
3. **근접중복 군집 단위로 분할** — 같은 조항은 어느 fold에 가든 한쪽에만 두도록
   군집을 만들어 배정한다. 이론상 가장 깨끗하지만 문서가 10개뿐이라
   문서 단위 분할과 충돌한다.

현재 기울기는 **1과 2를 함께**다. 전체 점수, 근접중복 제외 점수, 근접중복만의 점수를
셋 다 보고하면 어느 쪽 능력인지 읽을 수 있다.

그건 **라벨을 옳게 만드는** 작업이었고, 006은 **평가를 옳게 하는** 문제라 별개다.
