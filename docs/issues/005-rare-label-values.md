# 005. 희소 라벨 값

**상태**: 미해결

## 관측

주 라벨은 비교적 고르다.

```
통상수용 512 (50.0%) / 계약·질의검토 270 (26.4%) / 견적반영 242 (23.6%)
```

문제는 보조 축이다.

**`cost_basis`** — 7개 값 중 3개가 사실상 학습 불가능하다.

| 값 | 건수 |
|---|---:|
| 없음 | 611 |
| 고급·전문인력 | 162 |
| 복합 | 129 |
| 장비·인프라 | 74 |
| 라이선스 | 31 |
| 외주·전문기관 | 14 |
| **외부인증** | **3** |

**`blockers`** — 5종 모두 소수 클래스다. 754건(73.6%)은 아예 비어 있다.

| blocker | 건수 | 비율 |
|---|---:|---:|
| 범위·책임 | 142 | 13.9% |
| 검수·성능기준 | 83 | 8.1% |
| 라이선스·공급 | 79 | 7.7% |
| 기술실현성 | 51 | 5.0% |
| 공급자종속 | 30 | 2.9% |

## 영향

- `외부인증` 3건은 문서 단위 fold에서 **학습 fold에 한 건도 없는 경우가 생긴다.**
  평가에서 예측 자체가 불가능하다.
- `공급자종속` 30건도 fold당 평균 3건이라 F1이 극도로 불안정하다.
- 다중 라벨인 `blockers`는 조합이 32가지인데 대부분 조합의 관측이 0이다.

## 대응

- **fold 배정 시 희소 값의 분포를 확인한다.** 학습 fold에 0건인 값이 있으면
  그 값은 그 fold에서 평가 대상에서 뺀다.
- `cost_basis`는 예측 대상으로 쓸 때 **희소 값을 묶는 것**을 검토한다.
  `외부인증`·`외주·전문기관`은 "외부 조달"로 합칠 여지가 있다. 다만 이는 스키마 변경이라
  결정 기록이 필요하다.
- `blockers`는 조합 예측이 아니라 **종류별 이진 분류 5개**로 다루는 편이 현실적이다.
- 주 라벨(`primary_action`)을 주 평가 대상으로 두고, 보조 축은 보조 지표로 보고한다.

## 참고

`blockers`의 3회 반복 일치율이 40~67%로 낮게 관측된 바 있다(결정 22). 희소성과
불안정성이 겹쳐 있어 보조 축 단독 성능은 신뢰 구간을 넓게 잡아야 한다.
