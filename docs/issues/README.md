# 알려진 데이터 문제

`label_dataset_v1`(1,024건)에 남아 있는 문제를 하나씩 기록한다. 전처리·정리 과정에서
발견했지만 **고치지 않기로 했거나, 고치려면 판단이 필요한 것들**이다.

각 문서는 같은 형식을 따른다.

- **상태** — 미해결 / 완화 / 해결 / 수용(고치지 않기로 함)
- **관측** — 숫자. 재현 가능한 형태로.
- **영향** — 이 문제가 무엇을 망가뜨리는가
- **대응** — 지금 무엇을 하고, 무엇을 미뤘는가

결정의 근거는 [`../history/`](../history/)에, 실행 절차는 [`../PIPELINE.md`](../PIPELINE.md)에 있다.
여기는 **데이터 자체의 결함 목록**이다.

## 전제 — 학습 입력은 요구사항 원문이다

모델에 넣는 것은 요구사항 원문이고, 문서 ID·기관·유형·건수 같은 메타데이터는 **특징으로
쓰지 않는다.** 이 전제가 이슈의 심각도를 크게 바꾸므로 먼저 밝혀둔다.

메타데이터를 특징으로 쓰기 시작하면 001·002·003의 성격이 달라진다. 그때는 이 문서들을
다시 읽어야 한다.

| 전제 하에서 | 이슈 |
|---|---|
| **학습에 직접 영향** | 004(라벨 품질), 005(예측 대상), 006(원문 누수) |
| 평가 설계에서 다룸 | 003 |
| 분석·층화용으로만 필요 | 001, 002 |
| 입력에 넣지 않기로 함 | 007 |
| 라벨 생성 쪽 | 008 |
