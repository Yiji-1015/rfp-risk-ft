## 2026-08-19 11:15

- 결정: 파일럿 표본 40건에 대해 Zero-shot 3회 vs Dynamic Few-shot(층화) 3회 반복 일관성 비교 실험을 완료하였으며, Few-shot 층화 전략(`fewshot-stratified`)이 주 라벨 반복 일치율(92.5% vs 90.0%) 및 구축 난이도 일치율(92.5% vs 80.0%)에서 우수한 안정성을 보임을 실측 확인하였다.
- 이유:
  1. **주 라벨 3/3 일치율 향상**: Zero-shot(36/40, 90.0%) 대비 Few-shot(37/40, 92.5%)이 동일 입력에 대해 더 안정적인 주 라벨 판정을 생성함.
  2. **보조 축 판단 안정화**: `build_difficulty`(92.5% vs 80.0%)와 `cost_basis`(80.0% vs 72.5%)에서 Few-shot이 zero-shot보다 유의미하게 높은 반복 일치도를 보임.
  3. **다수결 기준 합치도 87.5% (35/40건)**: 판정 변동 5건 중 3건은 복합 기능 요구사항에 대해 통상 개발 범위(`통상수용`)로 눈높이가 맞춰진 결과이며, 1건(`SER-004`)은 포괄적 보안 배상 책임을 정확히 포착하여 `계약·질의검토`로 격상됨.
  4. **견적반영 앵커 보강 필요성 확인**: `견적반영` 앵커가 3건으로 부족하여 `견적반영 → 통상수용` 하향 이동(3건)이 관찰되었으므로, 전수 라벨링 전 앵커 풀 v2(`견적반영` 2~3건 추가) 확충 후 전수 실행을 진행함.
- 논문 메모:
  - 실험 조건: Claude Sonnet 5, `effort=medium`, `thinking=adaptive`, `max_tokens=16000`, 5분 프롬프트 캐시, 스키마 v4.0.0, 프롬프트 v5.
  - 3/3 일치율: 주 라벨 Zero 90.0% vs Few 92.5%, Blocker Zero 82.5% vs Few 67.5%, Cost Basis Zero 72.5% vs Few 80.0%, Build Diff Zero 80.0% vs Few 92.5%.
  - 총 240회 호출(Zero 120 + Few 120)에 소요된 총 비용은 약 5,058원이며, 프롬프트 캐싱을 통해 1건당 입력 비용의 90%를 절감함.
