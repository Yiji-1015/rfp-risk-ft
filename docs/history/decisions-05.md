# 연구 결정 기록 05

## 2026-08-25 15:08

- 결정: 남동발전 요구사항 101건의 빈 `requirement_type`을 원문 PDF의 11개 구역 제목과
  요구사항 ID 접두어의 대응으로 채우고, `requirements_v0.3.0` 및
  `label_dataset_v3`으로 새 버전을 만든다. 이전 동결본은 수정하지 않는다.
- 이유: 상세표 자체에는 유형 열이 없지만 원문은 각 표 묶음 바로 앞에서 유형을 명시한다.
  r2 PDF와 저장소 PDF의 요구사항 구간을 대조했고, 101건의 접두어 분포가 각 구역과
  충돌 없이 일치했다. v2 대비 변경 필드는 101건의 `requirement_type`과
  `requirement_type_source`뿐이며 라벨·본문은 동일하다.
- 논문 메모: 결측을 접두어만으로 추정한 것이 아니라 문서 구역 제목에서 복원했다.
  따라서 유형 근거는 `prefix` 101건에서 `text` 101건으로 바뀌며 전체 1,024건이
  `text`가 된다. 모델 입력은 요구사항 본문뿐이므로 기존 성능 결과는 변하지 않는다.

## 2026-08-25 15:37

- 결정: 유형 단독 모델은 만들지 않고, 정규화한 요구사항 유형 12종을 one-hot으로 만들어
  문자 TF-IDF 및 단어+문자 TF-IDF에 각각 결합했다. 원본 유형 표기 60종은 문서별 표현을
  직접 드러내므로 특징으로 쓰지 않았다.
- 이유: 사용 목적은 유형만으로 라벨을 맞히는 것이 아니라 본문 모델에 유형 맥락을 더했을
  때 일반화가 좋아지는지 확인하는 것이다. 같은 8/1/1 LODO와 balanced Logistic을 유지해
  유형 추가만 통제 비교했다.
- 논문 메모: 문자+유형은 macro F1 0.549, 정확도 0.616, 계약 recall 0.445로 문자 단독
  대비 -0.051(-0.159~+0.011), 우세 2/10이었다. 단어+문자+유형은 macro F1 0.558,
  정확도 0.623, 계약 recall 0.490으로 단어+문자 대비 -0.046(-0.180~+0.045), 우세
  1/10이었다. 유형은 문서별 라벨 분포와 얽혀 처음 보는 문서에서 불안정한 힌트가 된다.
  분석 메타데이터로는 유지하되 현재 모델 입력에서는 제외한다.

## 2026-08-25 16:38

- 결정: 유형 one-hot 블록 가중치 후보 `0 / 0.05 / 0.1 / 0.25 / 0.5 / 1.0`을 각 fold의
  학습 8문서로 학습하고 검증 1문서의 macro F1으로 선택했다. 동률이면 작은 가중치를
  택했으며 평가 문서는 선택에 사용하지 않았다.
- 이유: 고정 가중치 1에서 유형 결정 점수의 RMS가 본문보다 평균 1.327배 커, 불안정한
  유형 신호가 본문을 덮는다는 진단을 직접 검증하기 위해서다.
- 논문 메모: 문자+유형은 0.549에서 0.589로 회복했지만 문자 단독 0.601보다 -0.011
  (-0.159~+0.025), 우세 4/10이었다. 선택 가중치는 0/0.05/0.1/0.25/1.0이
  3/3/2/1/1개 fold였다. 단어+문자+유형은 0.558에서 0.584로 회복했지만 기준선
  0.603보다 -0.019(-0.159~+0.013), 우세 2/10이었다. 작은 가중치로 과대 영향은
  완화되지만, 검증 문서 하나에서 추정한 유형 효과가 다음 문서로 일반화되지 않는다.
  유형 특징은 채택하지 않는다.

## 2026-08-25 16:56

- 결정: 문자 TF-IDF 기준선에 `log(1+글자 수)`, 숫자 유무와 `log(1+숫자 개수)`, 그리고
  두 묶음의 결합을 각각 추가했다. 줄 시작의 `1)`, `2.` 같은 목록 번호는 숫자 집계에서
  제외했다. 목록 개수·단위·기준 표현은 문서 서식이나 표현 중복 위험 때문에 넣지 않았다.
- 이유: 본문 TF-IDF가 직접 표현하기 어려운 요구사항 크기와 정량 조건 밀도가 새 문서에도
  일반화되는지 한 번에 하나씩 통제 비교하기 위해서다. 수치 열의 표준화는 학습 fold에서만 했다.
- 논문 메모: 글자 수는 macro F1 0.571(기준선 대비 -0.030, 우세 2/10), 숫자 정보는
  0.587(-0.013, -0.111~+0.038, 우세 6/10), 전체 결합은 0.575(-0.026, 우세 3/10)였다.
  숫자 정보는 여러 문서에서 소폭 이득이 있지만 일부 문서의 큰 하락을 상쇄하지 못한다.
  현재 데이터에서는 세 구조·수치 feature를 채택하지 않고 문자 TF-IDF 0.601을 유지한다.

## 2026-08-25 17:22

- 결정: 본문 문자 TF-IDF와 본문에서 계산한 글자 수·숫자 정보만 유지한 채 Elastic-net
  Logistic, SVD100+Logistic 대조군, SVD100+XGBoost를 고정 초기 설정으로 비교했다.
  XGBoost에는 학습 fold의 클래스 분포로 계산한 balanced sample weight만 사용했다.
- 이유: 선형 모델에서 악화된 구조·수치 정보가 희소 선택이나 비선형 조건부 결합에서는
  유효한지 확인하되, SVD와 분류기 효과를 분리하기 위해 SVD+Logistic을 함께 뒀다.
- 논문 메모: Elastic-net은 macro F1 0.470(문자 기준선 대비 -0.131,
  -0.260~-0.049, 우세 0/10), SVD+Logistic은 0.532(-0.069, -0.197~+0.045,
  우세 1/10), SVD+XGBoost는 0.563(-0.038, -0.213~+0.079, 우세 3/10)이었다.
  XGBoost가 SVD Logistic보다 평균 0.031 높아 비선형 결합의 회복은 관찰됐지만, SVD로
  희소 문자 단서를 압축한 손실을 상쇄하지 못했다. 하이퍼파라미터 선택과는 별도 결과다.

## 2026-08-25 17:37

- 결정: 본문 문자 TF-IDF와 동결 E5를 결합하고, E5 블록 가중치 후보
  `0 / 0.05 / 0.1 / 0.25 / 0.5 / 1.0`을 fold별 검증 1문서의 macro F1으로 골랐다.
  같은 절차에 본문 유래 숫자 유무·개수를 추가한 모델도 분리 비교했다.
- 이유: 문자 TF-IDF의 정확한 표면 표현과 E5의 의미 표현이 상보적인지 확인하고, 숫자
  정보의 효과는 결합 모델과 분리해 측정하기 위해서다. 평가 문서는 선택에 쓰지 않았다.
- 논문 메모: TF-IDF+E5는 macro F1 0.611, 정확도 0.673, 계약 recall 0.508이었다.
  문자 단독 대비 +0.010(-0.029~+0.045), 우세 5/10이므로 숫자상 최고지만 안정적인
  개선으로 확정하지 않는다. 선택 가중치는 0/0.5/1.0이 각각 3/3/4개 fold였다.
  숫자 추가 모델은 0.592(문자 단독 대비 -0.009, -0.102~+0.047, 우세 6/10)로,
  숫자 없는 결합보다 평균 0.019 낮았다. 숫자 feature는 제외하고 TF-IDF+E5를 유망
  후보로 유지한다.

- 결정: 숫자 집계에서 줄 시작의 `1 |` 같은 표 행 번호도 제외하도록 보정하고, 숫자

- 논문 메모: 숫자 단독은 macro F1 0.591(-0.009, -0.098~+0.047, 우세 6/10),
  글자 수+숫자는 0.572(-0.029, -0.157~+0.031, 우세 3/10), Elastic-net은
  0.471(-0.129, -0.260~-0.071, 우세 0/10), SVD+Logistic은
  0.528(-0.072, -0.245~+0.020, 우세 1/10), SVD+XGBoost는
  0.564(-0.037, -0.213~+0.122, 우세 3/10)이었다. TF-IDF+E5+숫자는
  0.594(-0.007, -0.102~+0.066, 우세 7/10)로 숫자 없는 결합 0.611보다 0.017 낮았다.
  결론은 동일하다. 숫자 feature는 채택하지 않고 TF-IDF+E5를 유망 후보로 유지한다.
