# 연구 결정 기록 06

## 2026-08-27 16:06

- 결정: 설명 문구 클라우드에서 `제안사는`·`제안사가`처럼 RFP 작성 형식상 반복되는
  일반 주어가 상위 기여 문구로 나타난 현상을 **전처리 후보**로 기록한다. 현재 입력이나
  모델에서는 바로 제거하지 않는다.
- 이유: 이 표현은 계약 위험 내용보다 문장 작성 관습을 나타낼 가능성이 커 설명 근거로는
  유용하지 않다. 다만 924건 OOF 설명을 본 뒤 같은 평가셋에서 제거 효과를 재측정하면
  평가 결과에 맞춘 선택이 된다. 문서·라벨별 빈도와 오류 방향을 먼저 측정하고, 제거 또는
  마스킹 효과는 새 RFP나 별도 검증에서 확인해야 한다.
- 논문 메모: 설명 화면은 점수만으로 보이지 않던 **형식 신호 의존**을 발견하는 데
  유용했다. `제안사는`은 위험 원인이 아니라 모델이 이용한 상관 신호의 사례이며,
  후속 전처리 실험은 상투적 주어 하나만 바꾼 통제 비교로 설계한다.
