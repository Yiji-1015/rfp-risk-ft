  표준편차       0.0286        ← 평균 효과(0.0040)의 7배
  평균의 표준오차 0.0079        ← 평균이 0에서 0.50 SE

  |---|---:|
  | v4 조합 7/10 | **17.2%** |
  | v4 사전기준 8/10 | 5.5% |
  | v5 조합 6/13 | 70.9% |
  | v5 `char` 9/13 | 13.3% |
  | v5 사전기준 10/13 | 4.6% |

  **v4의 7/10은 효과가 0이어도 6번에 한 번 나오는 값이었다.** 사전 기준을 8/10(5.5%)로
  잡은 것이 그래서 옳았다. "양상이 달라졌다"가 아니라 **"그 양상이 실재하지 않았다"** 가
  정확한 서술이다.
